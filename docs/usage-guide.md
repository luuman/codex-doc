# Codex 详细使用方法

## 1. 这套项目是什么

`docs-workspace` 是一个多站点 Docusaurus 工作区。  
`codex` 是其中一个站点，对应目录和配置：

- 站点内容目录：`content/codex`
- 站点配置文件：`configs/codex.config.ts`
- 站点脚本：`package.json` 中的 `start:codex`、`build:codex`
- 子模块地址：`git@github.com:luuman/codex-doc.git`

## 2. 本地开发流程

### 2.1 安装依赖

在仓库根目录执行：

```bash
pnpm install
```

### 2.2 启动 Codex 站点

```bash
pnpm start:codex
```

默认访问地址：

- `http://localhost:3009/codex-doc/docs`

### 2.3 构建产物

```bash
pnpm build:codex
```

默认输出目录：

- `build/codex`

### 2.4 校验站点路径

```bash
pnpm check:site-paths
```

该命令会检查 `sites.json`、配置文件和导航中的路径是否一致。

## 3. 文档内容如何组织

`content/codex` 的关键结构：

- `docs/`：正文文档（Markdown/MDX）
- `blog/`：博客内容
- `sidebars.ts`：侧边栏自动生成配置

新增文档推荐做法：

1. 在 `content/codex/docs/` 下创建 `.md` 或 `.mdx` 文件。
2. 添加 front matter（如 `title`、`description`、`sidebar_position`）。
3. 启动 `pnpm start:codex` 本地预览。
4. 确认左侧侧栏出现新文档并检查链接。

## 4. 维护与发布建议

### 4.1 内容更新最小流程

1. 拉取主仓库与子模块最新代码。
2. 修改 `content/codex/docs` 或 `content/codex/blog` 内容。
3. 本地运行 `pnpm start:codex` 检查页面。
4. 本地运行 `pnpm build:codex` 验证可构建。
5. 提交变更并走仓库发布流程。

### 4.2 多站点联动注意点

如果改动了这些文件，需要注意影响其它站点：

- `src/shared-nav.ts`：顶部“全部站点”导航
- `sites.json`：站点元信息与部署映射
- `configs/site-config-factory.ts`：多站点公共配置工厂

## 5. 常见问题排查

### 5.1 启动后 404

重点检查：

- URL 是否带了 `baseUrl` 前缀：`/codex-doc/`
- 配置文件 `configs/codex.config.ts` 的 `baseUrl` 是否为 `/codex-doc/`

### 5.2 文档不显示在侧栏

重点检查：

- 文件是否放在 `content/codex/docs/` 下
- 文件 front matter 是否合法
- `sidebars.ts` 是否仍为自动生成（`autogenerated`）

### 5.3 静态资源路径错误

在 Markdown 中推荐使用相对路径，或确认资源放在站点可访问静态目录中。

## 6. 英文术语对应中文翻译

| English | 中文翻译 | 在本项目中的含义 |
| --- | --- | --- |
| Workspace | 工作区 | 承载多个文档站点的总仓库（`docs-workspace`）。 |
| Site | 站点 | 一个独立的文档站（如 `codex`、`moltbot`）。 |
| Docs | 文档 | 产品说明、指南、参考文档页面。 |
| Blog | 博客 | 时间序列文章内容模块。 |
| Sidebar | 侧边栏 | 文档目录导航配置（`sidebars.ts`）。 |
| Config | 配置 | Docusaurus 站点配置文件（`configs/*.config.ts`）。 |
| Base URL | 基础路径 | 站点部署时的 URL 前缀（如 `/codex-doc/`）。 |
| Build | 构建 | 生成可部署静态文件（`pnpm build:codex`）。 |
| Start (Dev Server) | 启动（开发服务） | 本地调试预览（`pnpm start:codex`）。 |
| Deploy | 部署 | 将构建产物发布到线上。 |
| Submodule | 子模块 | 外部仓库挂载到 `content/codex`。 |
| Branch | 分支 | 代码分支（如 `docs`）。 |
| Content Repo | 内容仓库 | 存放文档内容的源仓库（如 `luuman/codex-doc`）。 |
| Route | 路由 | 页面访问路径。 |
| Front Matter | 头部元数据 | Markdown 顶部 `---` 块中的配置。 |
| Markdown | Markdown 文档 | `.md` 文本格式文档。 |
| MDX | MDX 文档 | 可在 Markdown 中使用 JSX 组件。 |
| Plugin | 插件 | 扩展 Docusaurus 功能的模块。 |
| Theme | 主题 | 控制样式和界面表现。 |
| Mermaid | Mermaid 图表 | 在文档内绘制流程图/关系图。 |
| Broken Link | 失效链接 | 指向不存在页面或资源的链接。 |
