# Codex 产品概览

**Codex** 是 OpenAI 专为软件开发打造的编程智能体，已集成于 ChatGPT Plus、Pro、Business、Edu 和 Enterprise 方案中。

## 核心能力

### 1. 编写代码

描述你想要构建的内容，Codex 会生成与你意图相符的代码，并自动适应现有项目结构和编码规范。

### 2. 理解代码库

帮助读取和解析复杂代码或遗留代码，协助团队理解系统的整体组织架构。

### 3. 代码审查

分析代码，识别潜在的 Bug、逻辑错误和未处理的边界情况。

### 4. 调试与修复

追踪错误根因，诊断问题所在，并提出有针对性的修复方案。

### 5. 自动化任务

处理重复性工作流，包括代码重构、测试编写、数据库迁移和环境初始化等任务。

## 使用方式

Codex 提供多种接入方式，适应不同工作场景：

| 方式 | 适用场景 | 平台支持 |
|------|----------|----------|
| [Codex App](./app) | 多任务并行、Git 集成 | macOS（Apple Silicon） |
| [IDE 插件](./quickstart#ide-extension) | 编辑器内嵌集成 | VS Code、Cursor、Windsurf |
| [CLI 命令行](./cli) | 终端驱动、脚本集成 | macOS、Linux、Windows（实验性） |
| 网页端 | 云端任务、跨设备协作 | 浏览器（chatgpt.com/codex） |

## 订阅要求

使用 Codex 需要以下任一方案：

- ChatGPT Plus
- ChatGPT Pro
- ChatGPT Business
- ChatGPT Edu
- ChatGPT Enterprise
- OpenAI API 密钥（部分功能不可用）
