## 自动化场景

将重复性工作交给 Codex 定期自动执行：

### 代码质量
- 扫描每次提交，自动发现潜在 Bug
- 跟踪 CI 失败和测试不稳定问题（flakiness）

### 版本发布
- 从 PR 记录自动起草发布说明
- 汇总每日 Git 活动摘要

### 创意任务
- 定期生成小范围功能演示

## 使用场景分类

### 代码开发
- 从零实现新功能
- 重构现有模块，提升可维护性
- 编写单元测试和集成测试
- 处理数据库迁移脚本

### 代码理解
- 解释复杂的遗留代码
- 生成代码注释和文档
- 分析项目架构，绘制依赖关系

### 代码审查与修复
- 识别潜在安全漏洞
- 发现边界条件和未处理的错误
- 提供性能优化建议

---

## 最佳实践

1. **具体描述需求**：越具体的提示，越精准的结果
2. **提供验证标准**：告诉 Codex 如何判断任务完成
3. **利用迭代方式**：先完成基础实现，再逐步细化
4. **善用 Git 检查点**：在重要节点保存状态，便于对比和回退
