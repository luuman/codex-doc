Codex App 设置配置

通过 Settings 菜单或快捷键 Cmd+, 打开设置面板。

通用设置​

  • 控制文件打开行为和线程中命令输出的显示方式
  • 可要求 Cmd+Enter 发送多行提示（防止误触）
  • 任务执行期间防止系统进入睡眠

外观​

  • 主题：选择界面主题
  • 窗口透明度：调整窗口透明效果
  • 字体：分别自定义 UI 字体和代码字体（适用于 Diff 审查和终端）

通知​

  • 配置任务完成通知的触发时机
  • 管理通知权限请求

Agent 配置​

  • 设置与 IDE 插件和 CLI 共享
  • 常用选项可在应用内直接修改
  • 高级定制通过编辑 config.toml 实现

参考：安全配置 | 配置基础

Git 集成​

  • 分支命名规范：标准化 Codex 创建分支的命名格式
  • 强制推送：控制 Codex 是否可使用 git push --force
  • 提交消息模板：自定义提交信息的生成格式
  • PR 描述模板：自定义 Pull Request 描述的生成格式

集成与 MCP​

  • 通过模型上下文协议（MCP）连接外部工具
  • 启用推荐服务器或添加自定义 MCP 服务器
  • 支持 OAuth 认证（适用于需要身份验证的服务器）
  • 设置通过 config.toml 同步到 CLI 和 IDE 插件

个性化​

三种沟通风格可选：

模式说明
Friendly（友好）更多解释和友好互动
Pragmatic（务实）简洁直接的回复
None（关闭）不设定特定风格

自定义指令会更新 AGENTS.md 中的个人指令部分。

已归档线程​

  • 查看带有时间戳和项目上下文的历史归档对话
  • 通过 Unarchive 选项恢复线程
