# 键盘快捷键与命令

## 键盘快捷键

### 全局导航

| 快捷键 | 功能 |
|--------|------|
| `Cmd + Shift + P` 或 `Cmd + K` | 打开命令菜单 |
| `Cmd + ,` | 打开设置 |
| `Cmd + O` | 打开文件夹 |
| `Cmd + [` | 导航返回 |
| `Cmd + ]` | 导航前进 |

### 显示控制

| 快捷键 | 功能 |
|--------|------|
| `Cmd + +` 或 `Cmd + =` | 增大字体 |
| `Cmd + -` 或 `Cmd + _` | 减小字体 |
| `Cmd + B` | 切换侧边栏 |
| `Cmd + Option + B` | 切换 Diff 面板 |
| `Cmd + J` | 切换集成终端 |
| `Ctrl + L` | 清除终端 |

### 线程管理

| 快捷键 | 功能 |
|--------|------|
| `Cmd + N` 或 `Cmd + Shift + O` | 新建线程 |
| `Cmd + F` | 在线程中搜索 |
| `Cmd + Shift + [` | 切换到上一个线程 |
| `Cmd + Shift + ]` | 切换到下一个线程 |
| `Ctrl + M` | 语音输入 |

---

## 斜杠命令

在线程输入框中输入 `/` 激活斜杠命令菜单。

| 命令 | 功能 |
|------|------|
| `/feedback` | 提交反馈，可选择附带系统日志 |
| `/mcp` | 显示已连接的 MCP 服务器状态 |
| `/plan-mode` | 启用多步骤规划模式 |
| `/review` | 对未提交改动启动代码审查模式 |
| `/status` | 显示线程 ID、上下文使用量和速率限制 |

:::tip
使用 `$` 语法显式调用 Skills，Skills 也会出现在斜杠命令列表中。
:::
