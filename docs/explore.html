示例探索

以下是 Codex 的实际应用场景和启发性提示示例，帮助你发现更多可能性。

快速上手提示词​

复制以下提示词，直接在 Codex 中尝试：

在这个仓库里构建一个经典贪吃蛇游戏
找出并修复我代码库中的 Bug，只做高置信度的最小改动
为我的应用提出并实现一个高价值的病毒式传播功能
为 [你的需求] 创建一个仪表板
基于我的会议记录，创建一个交互式原型
分析一次销售通话，实现影响最大的缺失功能
解释我的应用架构中最主要的故障点
用我系统的架构写一个适合 5 岁小孩的睡前故事

集成外部工具​

Codex 可以通过 Skills 和 MCP 与外部工具集成，实现更强大的工作流：

内容与设计​

场景描述
生成 PDF为应用功能摘要生成 PDF 文档
实现 Figma 设计将 Figma 设计稿转化为可运行代码
生成视频/广告结合 Sora 生成演示视频或广告素材

部署与运维​

场景描述
Vercel 部署自动化部署到 Vercel 平台
GitHub CI/CD与 GitHub Actions 集成，自动化构建和测试
Sentry 监控通过 Sentry 集成查看和修复线上错误

数据与文档​

场景描述
数据库查询查询数据库并生成数据分析报告
电子表格从数据创建结构化 Excel/CSV 文件
文档生成生成路线图、技术规格文档

自动化场景​

将重复性工作交给 Codex 定期自动执行：

代码质量​

  • 扫描每次提交，自动发现潜在 Bug
  • 跟踪 CI 失败和测试不稳定问题（flakiness）

版本发布​

  • 从 PR 记录自动起草发布说明
  • 汇总每日 Git 活动摘要

创意任务​

  • 定期生成小范围功能演示

使用场景分类​

代码开发​

  • 从零实现新功能
  • 重构现有模块，提升可维护性
  • 编写单元测试和集成测试
  • 处理数据库迁移脚本

代码理解​

  • 解释复杂的遗留代码
  • 生成代码注释和文档
  • 分析项目架构，绘制依赖关系

代码审查与修复​

  • 识别潜在安全漏洞
  • 发现边界条件和未处理的错误
  • 提供性能优化建议

最佳实践​

  1. 具体描述需求：越具体的提示，越精准的结果
  2. 提供验证标准：告诉 Codex 如何判断任务完成
  3. 利用迭代方式：先完成基础实现，再逐步细化
  4. 善用 Git 检查点：在重要节点保存状态，便于对比和回退
