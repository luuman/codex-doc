# IDE 插件功能详解

IDE 插件与 Codex CLI 共享同一个智能体和配置，在编辑器内提供完整的 Codex 体验。

---

## 对话与代码编辑

- 在对话框中输入任务，可使用 `@` 语法引用特定文件
- 直接在编辑器中预览 Codex 建议的代码改动

---

## 模型选择

内置模型切换器，可在对话界面直接切换模型，无需命令行。

---

## 推理强度控制

提供三档推理强度设置：

| 档位 | 说明 |
|------|------|
| `low` | 速度优先 |
| `medium` | 均衡默认（推荐起点） |
| `high` | 深度推理，消耗更多 Token |

:::tip
从 `medium` 开始，只在必要时升级到 `high`——更高强度会更快触及速率限制。
:::

---

## 审批模式

| 模式 | 行为 |
|------|------|
| **Agent 模式**（默认） | 自动执行文件读取、编辑和命令；网络/目录访问需手动审批 |
| **Chat 模式** | 仅讨论和规划，不进行修改 |
| **Agent（完全访问）** | 所有操作无需审批（谨慎使用） |

---

## 云端委托

在配置好云端环境后，可以将耗时较长的任务卸载到云端执行：

1. 在 IDE 内监控任务进度
2. 本地与云端操作保持上下文连贯
3. 云端完成后，可在本地 diff 并测试

---

## 网络搜索

内置网络搜索功能，本地任务默认使用**缓存模式**（访问 OpenAI 预索引的结果）。

配置完全访问沙箱后，可启用**实时网络搜索**。

---

## 图像输入

在 Codex 面板中拖放图片时，**按住 Shift** 即可将图片作为上下文附加（截图、设计稿等）。

---

## 自动上下文（Auto Context）

IDE 插件自动包含：
- 当前打开的文件
- 选中的代码范围

可通过 `/auto-context` 斜杠命令开关此功能。

---

## 自定义选项

- **键盘快捷键**：通过 IDE 设置自定义（不同编辑器路径不同）
- **斜杠命令**：控制行为和模式切换（详见[斜杠命令](./slash-commands)）
- **插件设置**：模型、审批模式和默认值
- **侧边栏位置**：将 Codex 图标拖动到右侧边栏（如有需要）
