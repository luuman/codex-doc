# IDE 插件斜杠命令

## 使用方式

1. 在 Codex 对话框中输入 `/`
2. 从显示的列表中选择，或继续输入过滤
3. 按 **Enter** 执行

---

## 命令列表

| 命令 | 功能 |
|------|------|
| `/auto-context` | 开启或关闭自动上下文（自动包含最近打开的文件和 IDE 上下文） |
| `/cloud` | 切换到云端模式，在远程执行任务（需要云端访问权限） |
| `/cloud-environment` | 选择使用的云端环境（仅云端模式可用） |
| `/feedback` | 打开反馈对话框，可选择附带日志提交 |
| `/local` | 切换到本地模式，在工作区中执行任务 |
| `/review` | 启动代码审查模式，审查未提交改动或与基础分支对比 |
| `/status` | 显示线程 ID、上下文使用量和速率限制 |

---

## 核心功能说明

### 模式切换

`/local` 和 `/cloud` 命令可在本地执行与云端执行之间切换，无需重新打开对话。

### 上下文管理

`/auto-context` 控制 IDE 是否自动将当前打开的文件和选中内容附加到每条消息中。对于大型项目，可关闭此功能以精确控制上下文。

### 状态监控

`/status` 显示当前线程的关键信息：
- 线程 ID（用于支持问题排查）
- 上下文 Token 使用量
- 当前速率限制状态

### 代码审查

`/review` 启动内联审查工作流，可以：
- 审查所有未提交的改动
- 与指定基础分支对比
